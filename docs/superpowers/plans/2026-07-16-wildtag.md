# Wildtag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First-person web exploration game — tag critters with trackers and stay in radius; high-fidelity movement (dash/stamina/grapple/glide/rocket/ziplines/drones); light crafting tree.

**Architecture:** Three.js scene driven by a fixed-timestep game loop in plain TypeScript. All gameplay math lives in pure, Vitest-tested modules (`movement.ts`, `terrain.ts`, `ai.ts`, `progress.ts`, `recipes.ts`, rope/zipline math) that take state + dt and return new state; thin Three.js integration layers own meshes. Terrain is an analytic heightfield (`heightAt(x,z)`) — collision and AI never raycast meshes. HUD is a DOM overlay.

**Tech Stack:** Vite, TypeScript, three (^0.17x), Vitest. Playwright installed per-session for e2e. No physics engine, no React, no external 3D assets (all models procedural from three primitives).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-16-wildtag-design.md` — success criteria §9 are the definition of done.
- **Free flight must be impossible by construction**: glide vertical velocity clamped ≤ 0 relative to sink floor (always descending), rocket = single impulse + 4 s cooldown + max 1 per airtime, no hover anywhere.
- Deterministic world: single seed constant `WORLD_SEED = 1337` in `src/core/constants.ts`; all generation flows through seeded PRNG / noise. No `Math.random()` in world gen or AI spawn tables (fine for cosmetic particles).
- Pure-logic modules must not import `three` (import types only from `src/core/types.ts`; vectors in pure code are `{x,y,z}` plain objects).
- Debug handles on `window.__game` (see Task 14) — required for Playwright.
- Node ES modules; `npm test` = `vitest run`; `npm run dev` = vite on port **5199**.
- Commit after every task (conventional commits). All tuning constants in `src/core/constants.ts`, never inline.
- Units: meters, seconds, m/s. +Y up. World is 2048×2048 m centered on origin; sea level y=0.

Key shared types (defined once in `core/types.ts`, Task 2):

```ts
export type Vec3 = { x: number; y: number; z: number };
export type Biome = 'meadow' | 'forest' | 'wetland' | 'crags' | 'highlands' | 'water';
export type ResourceKind = 'fiber' | 'resin' | 'shard' | 'spark';
export interface MoveInput { forward: number; strafe: number; yaw: number; // radians
  sprint: boolean; jump: boolean; jumpHeld: boolean; dash: boolean; rocket: boolean; }
export interface MoveState {
  pos: Vec3; vel: Vec3; grounded: boolean; stamina: number; exhausted: boolean;
  coyote: number; jumpBuffer: number; dashCooldown: number; dashTime: number; dashDir: Vec3;
  airDashUsed: boolean; airRocketUsed: boolean; rocketCooldown: number;
  gliding: boolean; staminaRegenDelay: number;
  mode: 'normal' | 'zipline' | 'swim'; }
export interface GroundQuery { heightAt(x: number, z: number): number;
  normalAt(x: number, z: number): Vec3; }
export interface SpeciesDef { id: string; name: string; biomes: Biome[];
  size: number; walkSpeed: number; fleeSpeed: number; awareness: number;
  fleeStyle: 'sprint' | 'zigzag' | 'fly' | 'swim' | 'ledge' | 'none';
  trackRadius: number; trackTime: number; rarity: number; // spawn weight
  rewardSparks: number; rewardRP: number; }
export interface CritterState { id: number; species: string; pos: Vec3; vel: Vec3;
  yaw: number; state: 'idle' | 'wander' | 'alert' | 'flee' | 'calm';
  stateTime: number; targetYaw: number; tagged: boolean; linked: boolean;
  trackProgress: number; home: Vec3; flightHeight: number; }
```

### Task 2: Deterministic core — rng, noise, terrain (TDD)

**Files:** Create `src/core/rng.ts`, `src/core/types.ts`, `src/world/noise.ts`, `src/world/terrain.ts`; Test `tests/terrain.test.ts`, `tests/rng.test.ts`.

**Interfaces — Produces:**
- `mulberry32(seed: number): () => number` (floats [0,1)); `hash2(seed: number, x: number, y: number): number` (deterministic per int coords).
- `makeNoise2D(seed: number): (x: number, y: number) => number` (range [-1,1], smooth).
- `heightAt(x: number, z: number): number` — pure fn of `WORLD_SEED`. Island: radial falloff so beyond ~950 m radius terrain drops below sea level (y=0). Meadow rolling hills 2–10 m, forest 8–30 m, crags spires up to ~90 m with steep noise, highlands plateau 60–110 m, wetland basin ~0.5–3 m with lakes (regions where height < 0.4 dip below 0).
- `biomeAt(x: number, z: number): Biome` — derived from height + a moisture noise channel + radial sector so all 5 biomes reachably exist: meadow around spawn (0,0), forest N/NE, wetland S, crags W, highlands NW rising. `'water'` where `heightAt < 0.2`.
- `groundNormalAt(x: number, z: number): Vec3` via central differences (eps 0.5).

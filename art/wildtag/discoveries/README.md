# Small-wonder source art

`small-wonders.blend` contains the **Wildtag Small Wonders** scene, with one
collection per discovery. All 18 scenes are original Blender MCP models using
softened wood, stone, pottery, brass, paper and vertex-painted foliage. No
external textures or downloaded models are required.

Layout and collision data live in `src/discoveries/data.json`, generated by:

```sh
node scripts/wildtag/discoveries/layout.mjs
```

With Blender's MCP bridge running on localhost:9876 and the project's MCP
client environment installed, rebuild from the repository root:

```sh
BLENDER_TIMEOUT_SECONDS=1200 .codex-drafts/blender-mcp/venv/bin/python \
  scripts/wildtag/blender/mcp_client.py code \
  scripts/wildtag/discoveries/build_models.py
python3 scripts/wildtag/check_assets.py
npm run build
```

The authoring script uses a dedicated scene, restores the previously selected
scene and exports `public/wildtag/models/discovery_*.glb`. It also writes the
manifest entries and a SHA-256 of the collision layout. A `DISCOVERY_ONLY` list
of site IDs can be supplied in a wrapper script for selective re-exports.

Coordinates in the helper calls are game coordinates: +Y up, +Z toward the
usual approach. Blender conversion happens in the helpers and glTF export.
`pitched_box` rotates roofs around their own centers. Avoid rotating a mesh
whose vertices already contain its scene position around the origin.

Empties tagged with `curioMotion`, `phase`, `speed` and `amplitude` are preserved
as runtime pivots. Meshes are joined only within the same immediate parent,
then the runtime merges stationary pieces. Keep those parent relationships
intact when editing a moving detail.

The complete discovery collection has a 100,000-triangle validation ceiling.
Use shared `Discoveries_` materials and avoid additional lights, texture maps
or shadow-casting animated ornaments for these small ambient scenes.
